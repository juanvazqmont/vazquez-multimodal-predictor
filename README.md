# Multimodal Target Predictor - Deployment App

This is a standalone **Streamlit** application designed to predict target values using a **Hybrid Ensemble Model**. It combines structured tabular data (via CatBoost) and unstructured image data (via ResNet18 feature extraction) to generate accurate predictions with uncertainty quantification.

---

## Prerequisites & Restrictions

To ensure the application runs correctly, please strictly adhere to the following environment requirements:

* **Python Version:** **3.9** or **3.10** (Strict requirement as per project specs).
* **Operating System:** Windows, macOS (Intel/Silicon), or Linux.
* **Hardware:** 4GB+ RAM recommended. No GPU is required for inference (runs on CPU by default).

### Required Libraries
The application relies on specific versions of the following libraries (install via `requirements.txt`):
* `torch >= 2.1.0`
* `torchvision >= 0.16.0`
* `catboost >= 1.2.2`
* `streamlit >= 1.28.0`
* `pandas`, `numpy`, `Pillow`

## Directory Structure

Ensure your deployment folder follows this exact structure before running:

```text
deployment/
├── app.py                  # Main application script
├── requirements.txt        # Dependencies file
├── README.md               # This file
└── models/                 # MUST contain the trained ensemble
    ├── catboost_model_0.cbm
    ├── catboost_model_1.cbm
    ├── catboost_model_2.cbm
    └── metadata.pkl        # Critical feature scaling metadata


Note: The app will automatically create a model_weights/ folder to store the ResNet18 backbone weights upon the first run.

## Installation & Setup

**Open a terminal** and navigate to the deployment folder:
```bash
cd deployment
```

**Create a virtual environment** (Recommended to avoid conflicts):
```bash
# For Windows
python -m venv venv
venv\Scripts\activate

# For Mac/Linux
python3 -m venv venv
source venv/bin/activate
```

**Install Dependencies:**
```bash
pip install -r requirements.txt
```

**Launch the App:**
```bash
streamlit run app.py
```


## Usage Guide

The application offers two modes of operation via the sidebar:

### Method 1: CSV Upload (Batch Processing)

Best for testing multiple rows at once.

  1.  Select "Upload CSV" from the radio button.

  2.  Upload a CSV file containing the tabular features.

       * Required columns: yyz, qgg, lux, image (filename).

       * Optional columns: date (YYYY-MM-DD), bar, baz, xgt, etc.

  3.  Upload the Image File corresponding to the row you wish to predict.

       *  Note: Currently, the app processes one image at a time against the tabular data provided.

Method 2: Manual Entry (Single Prediction)

Best for quick "what-if" analysis.

    1. Select "Manual Entry" from the radio button.

    2. Fill in the form fields:

        * Date: Used for cyclical feature engineering (Sine/Cosine transforms).

        * Numerical Features: Enter values for yyz, qgg, lux, etc.

    3. Upload Image: Upload a .jpg or .png file to be processed by the CNN.

    4. Click "Generate Prediction".


## Understanding the Output

The model provides two key metrics:

    1. Predicted Target ($): The estimated value generated by the ensemble.

    2. Uncertainty (±$): The standard deviation across the ensemble models.

        🟢 Green (High Confidence): Uncertainty is < 10% of the prediction.

        🟡 Yellow (Medium Confidence): Uncertainty is 10-20% of the prediction.

        🔴 Red (Low Confidence): Uncertainty is > 20% of the prediction.

## Troubleshooting

    * "Model Path not found": Ensure the models/ folder exists in the same directory as app.py and contains the .cbm and .pkl files.

    * "Internet Connection Error": On the very first run, the app needs internet access to download the ResNet18 weights from PyTorch.

    * "Column missing error": If uploading a CSV, ensure headers match the training data exactly (e.g., yyz, qgg, lux).
